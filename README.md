# Azzurro — アドリア海の午後

アドリア海の島々の上を赤い飛行艇がゆったり飛んでいく様子を眺める 3D 映像作品です。
写実よりも「手描きアニメの一場面」らしさを優先して、すべてトゥーン調のカスタムシェーダーで描いています。

## 起動

```bash
mise install        # Node.js 24 LTS / pnpm を導入
pnpm install
pnpm dev            # http://localhost:5173
```

| コマンド      | 内容                                     |
| ------------- | ---------------------------------------- |
| `pnpm dev`    | 開発サーバー (Vite)                      |
| `pnpm build`  | 型チェック + 本番ビルド (`dist/`)        |
| `pnpm lint`   | Oxlint                                   |
| `pnpm format` | Oxfmt で整形 (`format:check` で検査のみ) |
| `pnpm check`  | typecheck + lint + format:check          |

`?q=low` を付けると低負荷モード（解像度 1x）になります。フレームレートが落ちた場合も自動で解像度を下げます。

## 操作

- 何もしなければ「監督モード」で 8 種類のカメラワーク（追走・水平線・僚機・通過・操縦席・碧い海・正面・波間）が順に切り替わります
- ドラッグ: 飛行機の周りを自由視点で回る / `F`: 監督⇄自由視点
- `Space`: 次のショット、`1`〜`8`: ショットを直接選択
- `M`: 環境音（風・プロペラ・カモメ、すべて Web Audio で合成）
- `H`: UI を隠す

## 見どころと仕組み

| 要素   | 実装                                                                                                                                      |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 空     | グラデーション + 太陽のグロー + 流れる巻雲・高積雲（`src/world/sky.ts`）                                                                  |
| 積雲   | 球の集合をノイズで変形した「もこもこ」雲。平らな底、青い陰、逆光時の銀の縁取り、頂点シェーダーでゆっくり湧き立つ（`src/world/clouds.ts`） |
| 光芒   | 雲の切れ間から海へ降りる光の帯（天使の梯子）と、太陽を見上げた時のスクリーンスペース・ゴッドレイ（`clouds.ts` / `src/post/pipeline.ts`）  |
| 海     | Gerstner 波 + 水深テクスチャによる浅瀬のターコイズ、コースティクス、太陽のきらめき、波打ち際の泡、雲と飛行機の影（`src/world/ocean.ts`）  |
| 島     | 断崖・丘・尖塔・低い島の 4 タイプを手続き生成。石灰岩の地層、糸杉・笠松、赤瓦の村、灯台（`src/world/terrain.ts`, `islands.ts`）           |
| 船     | 帆船・オレンジ帆のラガー・漁船・汽船が波に揺られて周回し、ケルビン波の航跡を曳く（`src/world/boats.ts`）                                  |
| 鳥     | カモメの群れ。GPU で羽ばたき、群れごとに旋回（`src/world/birds.ts`）                                                                      |
| 飛行艇 | プッシャー式の赤い飛行艇をプリミティブから組み立て、輪郭線付き。地形を避ける飛行経路と旋回バンク（`src/world/plane.ts`）                  |
| 仕上げ | ブルーム、暖色寄りのグレーディング、ビネット、Neutral トーンマッピング                                                                    |
